# Video rules

The source brief is the authoritative ruleset. This copy keeps the build self-contained.

- Profiles supply colours, fonts, logo, and corner radius; page data never does.
- Text is kept inside 96px (landscape) or 120px/72px (portrait) safe margins.
- Every end card shows the fixed AI-disclosure line and is at least three seconds.
- Script claims must occur in source data; banned claims never render.
