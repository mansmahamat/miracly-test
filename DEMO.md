# Five-minute demo runbook

1. Run `npm run dev` and open `http://localhost:3000`.
2. In another terminal run `npm run worker`.
3. Submit `data/confetti-kol-marketing-agency-services-singapore.json` with the curl command in the README.
4. Show `GET /jobs/<id>` progressing to review, then expand the matching card in the review UI.
5. Play the 16:9 and 9:16 cuts, add a note and approve the draft.
6. Call `POST /jobs/<id>/publish` and show `public/confetti-kol-marketing/` plus `public/video-sitemap.xml`.
7. Close by showing `output/batch-report.json`, including the three `needs-human` source files and their clear validation reasons.

For the recording, start with the review UI and use terminal commands only for the API and published artifacts. Keep it under five minutes.
